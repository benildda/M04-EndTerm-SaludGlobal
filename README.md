# Salud Global

## Descripción del proyecto

Salud Global es una aplicación web desarrollada para la asignatura M04 - Lenguajes de marcas y sistemas de gestión de información.

Su objetivo es permitir a los usuarios consultar información sobre enfermedades a nivel mundial y conocer su afectación en diferentes países y grupos de población.

## Objetivos

- Consultar información sobre diferentes enfermedades.
- Buscar y filtrar enfermedades.
- Mostrar estadísticas y datos procedentes de una API pública.
- Presentar información de forma clara y accesible.
- Adaptar la página a dispositivos móviles y ordenadores.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS3:** diseño y adaptación a diferentes pantallas mediante Grid y Flexbox.
- **JavaScript Vanilla:** interacción con el usuario y consulta de datos.
- **Git y GitHub:** control de versiones.
- **Vercel:** publicación de la aplicación web.

## Estructura del proyecto

- `index.html`: página principal.
- `css/styles.css`: hoja de estilos.
- `js/main.js`: funcionalidades JavaScript.
- `README.md`: documentación del proyecto.
- Carpeta de recursos: imágenes y otros elementos gráficos.

## Funcionalidades previstas

- Consulta de enfermedades.
- Filtros por enfermedad, país y año.
- Clasificación por número de personas afectadas, cuando existan datos comparables.
- Visualización de resultados en una tabla.
- Información detallada de las enfermedades.
- Cambio entre modo claro y oscuro.

## Fuente de datos

Está prevista la utilización de una API pública de información sanitaria.

La fuente y los indicadores definitivos están pendientes de validación.
